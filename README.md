# Tablorigolo

Un jeu d'opérations croisées pour réviser les tables de multiplication, pensé pour une tablette.

## Comment jouer

1. Choisir les tables à réviser (de 1 à 10), la difficulté et la taille de la grille, puis toucher **Jouer**.
2. Toucher une case vide, puis taper le nombre avec le pavé numérique (⌫ efface, ➜ passe à la case suivante).
3. Toucher **Vérifier** : les cases fausses passent en rouge, il suffit de les corriger.
4. Quand tout est juste : feu d'artifice, puis bouton **Rejouer** pour une nouvelle grille.

Chaque grille est générée au hasard, avec les tables choisies. Les opérations se croisent et partagent des cases, comme sur un jeu de mots croisés.

## Fichiers

Un seul fichier : `index.html`. Il fonctionne sans connexion, sans installation.
